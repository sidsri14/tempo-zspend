# Introduce a Web3 Project to Segmento — submission copy ($300 USDC, 4 subs)

## Short intro (~150 words)
Segmento is a crypto-native growth suite — analytics, on-chain attribution, and CRM for
web3 teams. Here's a project it should power:

**Z-Spend** — an agentic treasury whose budget is enforced on-chain. It's a great Segmento
demo because every spend is a verifiable on-chain event (policy APPROVE/REJECT + chain
reverts on allowance exhaustion). Run Z-Spend through Segmento and you can show real
treasury activity against funnel goals — where funds go, which agent operations convert,
and where policy blocks churn before it happens.

Why it fits: Segmento targets teams that need data-driven growth; Z-Spend generates a
clean, audit-ready event stream that makes that funnel analysis trivial. It's live on
Tempo testnet with reproducible proof (transcript + demo video in the repo).
