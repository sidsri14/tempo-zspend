Z-Spend

On-chain-enforced agentic treasury — an AI agent that cannot overspend, even with its own key.
Tempo Track · Crypto World's Fair · Live on Moderato testnet

The Problem

Agentic AI wallets hold real funds, but "trust the agent" fails. A stolen or misconfigured key can drain the treasury. DeFi multisigs don't scale to agent autonomy.

The Build — 2 Legs of Defense

1. Policy layer (off-chain, fail-closed)
  • Per-category daily caps, per-recipient caps, max single payment, reserve floor
  • Every spend = verdict computed from immutable JSONL ledger
  • 7/7 unit tests passing
2. On-chain enforcement (Tempo native)
  • Agent signs as an authorized access key with pathUSD limit + scope
  • Protocol enforces tip-1011 scopes + spend limits at tx validation
  • Compromise the key — still can't exceed the allowance
